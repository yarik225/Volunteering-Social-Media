# Volunteer & Leadership Platform

A centralized platform designed to help students discover, organize, and participate in volunteering, leadership, and school-related opportunities.

## 🚀 Features

### 🏠 Home
- Recent, upcoming, and time-sensitive opportunities (next 1–2 hours)
- Messages from other users
- Personalized “For You” volunteering page
- Events you’ve signed up for

---

## 📅 Opportunities & Events

### 🎉 Events
Categorized into:
- In-school events
- Out-of-school events

### 🤝 Volunteering Opportunities
- Browse and sign up for volunteer work

### 🧠 Leadership
- Discover leadership roles and positions

### 🗺 Map
- View opportunities by location

### 🎁 Special Offers
- Exclusive deals or perks tied to participation


---

## 👤 User Profile

- Name, Age, Profile Picture *(pulled from InnerView API)*
- Saved opportunities
- Your posts
- Connected via InnerView API

---

## ➕ Add Opportunity

Users can create new opportunities with the following fields:
- Name
- Description + requirements + link
- Location
- Number of people required
- Time and date
- Tags *(e.g., STEM, Business, etc.)*
- Contact information

## About

**Volunteering Social Media** is a lightweight, browser-based platform that brings together students who want to give back to their communities. Users can discover volunteering opportunities, create and view profiles, and engage with a like-minded social network — all from a clean and accessible web interface.

---

## Features

- 🏠 **Home Feed** — Browse volunteering posts and community updates
- 👤 **User Profiles** — View and manage personal volunteer profiles
- 📱 **Responsive Design** — Optimized for both desktop and mobile devices
- ⚡ **No Dependencies** — Runs entirely in the browser with no build step required

## Getting Started

Since this is a static front-end project, no installation or build tools are needed.

### Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yarik225/Volunteering-Social-Media.git
   ```

2. **Navigate into the project folder:**
   ```bash
   cd Volunteering-Social-Media
   ```

3. **Open `index.html` in your browser:**
   ```bash
   # macOS
   open index.html

   # Windows
   start index.html

   # Linux
   xdg-open index.html
   ```

> Alternatively, you can use a local development server like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code for a better development experience.
